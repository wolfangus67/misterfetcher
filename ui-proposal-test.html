UI direction proposal

Less control panel, more private media workspace.

Direction 1

Account-first framing The UI should make “this belongs to me” obvious everywhere, especially for addons and catalogs.

Direction 2

Chunk the complexity Move away from long admin forms and toward grouped cards, summaries, and progressive detail.

Direction 3

Warmer visual language Less generic dark dashboard, more crafted workspace with texture, hierarchy, and breathing room.

This is a standalone visual proposal only. It does not modify the app code or connect to the real backend.
